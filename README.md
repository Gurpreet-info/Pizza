# 🍕 Pizza

This is a Pizza Store web application built using Laravel.

## 🚀 Features

- Menu management
- Offers & discounts
- Cart system
- Order management
- Admin panel

## 🛠 Tech Stack

- Laravel (Backend API)
- React (Frontend)
- MySQL Database

## 📦 Setup

```bash
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
